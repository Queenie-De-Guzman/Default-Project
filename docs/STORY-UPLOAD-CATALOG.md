# EduPlay Recommended Story Upload Catalog

This catalog is **upload guidance**, not bundled third-party story text. EduPlay ships original or teacher-authorized materials only. The titles below are topic ideas for teachers to write, adapt, license or upload as **original, public-domain or otherwise authorized** versions. Do not upload copyrighted third-party stories merely because a title or link appears here.

The attached starter pack is included under `docs/story-library-starter-pack/`. It contains ten **original sample manuscripts** (DOCX), their catalog and a README. Run `npm run import-stories` while the server is running to upload each DOCX into My Learning Materials and create a corresponding draft story with sections, vocabulary and answer keys. The command is idempotent: it updates existing records by title instead of duplicating them. A fresh install has an empty library; run `npm run clear-library` to remove every story and imported teaching material again. In **Teacher → Story Library → Add story**, choose **Upload file** and simply pick a PDF/document: EduPlay fills the basic details from the filename and opens the result as a flip book preview with Read Aloud. Choose **Write manually** to type the story text instead; each section becomes a page in the same flip book. Details can be edited later.

## How to use this catalog

1. Open **Teacher → Story Library → Add story**.
2. Pick **Upload file** for a PDF/document, or **Write manually** to type the story. Only that one source is required; other details are optional.
3. Choose or create an original/licensed version of a suggested topic.
4. The story opens as a flip book; review sections/pages, then add vocabulary and comprehension checks.
5. Use **Analyze** or **AI Game Generator** to create narration support, a Teacher's Guide, quizzes and game drafts.
6. Review every generated item and publish only after verifying curriculum alignment and source accuracy.

## Library categories for this catalog

EduPlay's original eleven required categories remain available: Short Stories, Moral Stories, Fables and Folktales, Animal Stories, Adventure Stories, Filipino Stories, English Stories, Science Reading, Historical Stories, Vocabulary Reading and Reading Comprehension.

The catalog adds filter categories for: Values Education, Science and Nature, Mathematics, Philippine Culture and History, Health and Safety, Environmental Education and Adventure and Imagination.

## Features generated from every uploaded story

EduPlay derives these from the teacher's actual uploaded text; unclear or missing information is flagged for review instead of invented.

- **Read Aloud** — whole-story and per-section narration with word/sentence highlighting.
- **Vocabulary Builder** — difficult words with definitions, example sentences and source quotes.
- **Comprehension Quiz** — multiple-choice, true/false and short-answer drafts.
- **AI Learning Games** — word matching, word scramble, story sequencing, picture quiz and other registered game drafts.
- **Teacher's Guide** — learning objectives, discussion questions, classroom activities and a source-grounded key takeaway.

**Policy reminder:** suggested competency codes are never fabricated. Teachers must enter and verify official DepEd/MATATAG codes from their own curriculum documents before publishing aligned materials.
